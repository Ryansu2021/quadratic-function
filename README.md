# 二次函數：解題前的四個動作

國中九年級二次函數的問題導向互動網頁。以 111–115 年國中教育會考二次函數題的全國通過率為起點，把五題拆成四個可操作的解題動作：

1. **定位**：先找頂點，再看開口（會考 113、115）
2. **對摺**：一樣高的兩點，對稱軸在正中間（會考 112、111）
3. **邊界**：頂點是一道牆，牆外的 y 值不會出現（會考 115）
4. **追蹤**：平移時先問誰在動、怎麼動（會考 111、114）

最後的「解題羅盤」把四個動作接回紙本題目的線索。網頁中不放考題，學生操作的是解題的核心概念。

## 使用方式

單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可；也可用 GitHub Pages 發佈。版面會依視窗大小等比例縮放成一頁一畫面，右上角可切換全螢幕投影。
